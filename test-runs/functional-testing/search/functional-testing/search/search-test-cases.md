# Тест-кейсы: поиск товаров

## 1. Общая информация

**Тестируемое приложение:** Flora&Co — интернет-магазин растений  
**Раздел:** Каталог → Поиск  
**Тип тестирования:** Функциональное тестирование  
**Связанное требование:** [REQ-SEARCH-001 — Поиск товаров по названию](search-requirements.md)
### Общие предусловия

- Открыт каталог товаров.
- Выбрана категория «Все товары».
- Корзина пуста.
- Избранное пусто.

Если в конкретном тест-кейсе указаны другие предусловия, используются они.

### TC-SEARCH-008 — Сохранение поискового запроса при переключении категории

**Предусловия:**
- Открыт каталог.
- Выбрана категория «Все товары».
- В корзине 0 товаров.
- В избранном 0 товаров.

**Шаги:**
1. Ввести `не`.
2. Проверить отображаемые товары.
3. Переключить категорию на «Клематисы».
4. Проверить отображаемые товары и содержимое поля поиска.
5. Вернуться в категорию «Все товары».
6. Проверить отображаемые товары и содержимое поля поиска.

**Ожидаемый результат:**
- В категории «Все товары» отображаются «Снежная Гавань» и «Сиреневая Вуаль».
- В категории «Клематисы» отображается только «Сиреневая Вуаль».
- Значение `не` сохраняется в поле поиска при переключении категорий.
- После возврата в категорию «Все товары» снова отображаются «Снежная Гавань» и «Сиреневая Вуаль».
- Поисковый запрос по-прежнему находится в поле поиска.

**Фактический результат:** соответствует ожидаемому.

**Статус:** PASS

### TC-SEARCH-009 — Изменение уже введённого поискового запроса

**Предусловия:** общие.

- После изменения запроса на `ат` отображаются «Розовый Атлас» и «Фиолетовый Бархат».
- «Дикая Роза» больше не отображается.

**Фактический результат:** соответствует ожидаемому.

**Статус:** PASS

## 3. Исследовательские наблюдения

Следующие сценарии были проверены, но для них пока не согласовано отдельное требование. Поэтому результаты фиксируются как наблюдения, а не как подтверждение соответствия требованиям.

### OBS-SEARCH-001 — Поиск по строке из пробелов

**Действие:** ввести в поле поиска один или несколько пробелов.

**Фактический результат:** отображаются все карточки товаров независимо от количества введённых пробелов.

**Оценка:** ожидаемое поведение требует уточнения.

### OBS-SEARCH-002 — Пустая строка поиска

**Наблюдение:** пустую строку невозможно ввести как поисковый запрос, поскольку поиск начинается автоматически после ввода первого символа.

**Оценка:** отдельная проверка сброса поиска не выполнена. Возможность очистки поля одним действием предложена в ENH-001.
