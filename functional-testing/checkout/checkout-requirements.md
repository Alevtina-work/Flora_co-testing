# Требования к форме оформления заказа

## REQ-CHECKOUT-001 — Имя покупателя

**Требование:** Поле «Имя» обязательно для заполнения. Введённое значение должно содержать хотя бы одну букву.

**Подтверждение:** Требование уточнено у разработчика.

## REQ-CHECKOUT-002 — Фамилия покупателя

**Требование:** Поле «Фамилия» обязательно для заполнения. Введённое значение должно содержать хотя бы одну букву.

**Подтверждение:** Требование уточнено у разработчика.

## REQ-CHECKOUT-003 — Электронная почта

**Требование:** Поле электронной почты обязательно для заполнения.

**Дополнительная информация:**
- Поле допускает латинские буквы, цифры и некоторые специальные символы, необходимые для ввода адреса.
- Проверка корректности формата электронной почты в текущей версии не реализована.

**Подтверждение:** Текущая логика поля уточнена у разработчика.

## REQ-CHECKOUT-004 — Номер телефона

**Требование:** Для оформления заказа необходимо указать номер телефона, содержащий ровно 10 цифр после префикса `+7`.

**Дополнительная информация:**
- Префикс `+7` подставляется автоматически.
- Удалить префикс нельзя.
- После префикса пользователь может вводить только цифры.
- Ввод ограничен десятью цифрами.

**Подтверждение:** Требование уточнено у разработчика.

## REQ-CHECKOUT-005 — Способ доставки

**Текущее поведение приложения:**
- Пользователь может выбрать самовывоз или доставку почтой.
- При выборе доставки почтой отображается поле для ввода адреса.

**Требует уточнения:** Является ли адрес обязательным для оформления заказа и какие правила его проверки должны применяться.

## REQ-CHECKOUT-006 — Способ оплаты

**Текущее поведение приложения:**
- Доступны варианты «Онлайн» и «При получении».
- Оплата при получении доступна только при выборе самовывоза.
- При выборе доставки почтой оплата при получении недоступна.

## REQ-CHECKOUT-007 — Отправка заказа

**Текущее поведение приложения:**
- При заполнении формы корректными данными заказ оформляется.
- Если обязательные поля не заполнены, приложение показывает предупреждение и не оформляет заказ.
- При пустой корзине приложение также показывает предупреждение.

**Требует уточнения:** Точный текст предупреждений и правила их отображения отдельно не согласованы.

---

## Замечания и ограничения

1. Проверка формата электронной почты в текущей версии отсутствует. Это подтверждённое решение для текущего этапа разработки.
2. Для имени и фамилии на текущем этапе достаточно наличия хотя бы одной буквы. Дополнительные ограничения на расположение пробелов и дефисов не входят в согласованные требования.
3. Правила проверки адреса доставки пока не определены.
4. Требования могут дополняться после уточнения поведения приложения у разработчика.
