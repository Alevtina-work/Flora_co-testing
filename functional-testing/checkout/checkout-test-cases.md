# Тест-кейсы формы оформления заказа

**Связанные требования:** [Требования к форме оформления заказа](checkout-requirements.md)

## Предусловия

- Открыта страница оформления заказа.
- В корзине находится хотя бы один товар.
- Все поля, кроме проверяемого, заполнены корректными значениями.
- Для проверок, не связанных со способом доставки и оплаты, выбраны самовывоз и доступный способ оплаты.

## Тест-кейсы

### TC-CHECKOUT-001 — Проверка имени, содержащего только дефисы

**Связанное требование:** REQ-CHECKOUT-001

**Шаги:**
1. В поле «Имя» ввести `---`.
2. Заполнить остальные обязательные поля.
3. Нажать кнопку оформления заказа.

**Ожидаемый результат:** Заказ не оформляется, поскольку значение поля «Имя» не содержит букв.

**Фактический результат:** Заказ оформляется.

**Статус:** FAIL

---

### TC-CHECKOUT-003 — Отправка формы с пустым полем электронной почты

**Связанное требование:** REQ-CHECKOUT-003

**Шаги:**
1. Оставить поле электронной почты пустым.
2. Заполнить остальные обязательные поля.
3. Нажать кнопку оформления заказа.

**Ожидаемый результат:** Заказ не оформляется. Приложение показывает предупреждение о незаполненных данных покупателя.

**Фактический результат:** Заказ не оформляется, появляется предупреждение.

**Статус:** PASS

---

### TC-CHECKOUT-004 — Ввод электронной почты без проверки формата

**Связанное требование:** REQ-CHECKOUT-003

**Тестовые данные:** `test`

**Шаги:**
1. Ввести `test` в поле электронной почты.
2. Заполнить остальные обязательные поля.
3. Нажать кнопку оформления заказа.

**Ожидаемый результат:** В текущей версии приложение принимает значение, если оно состоит из разрешённых символов. Проверка формата электронной почты не выполняется.

**Фактический результат:** Заказ успешно оформляется.

**Статус:** PASS

### TC-CHECKOUT-005 — Оформление заказа с полным номером телефона

**Связанное требование:** REQ-CHECKOUT-004

**Тестовые данные:** `+71234567890`

**Шаги:**
1. Ввести 10 цифр после префикса `+7`.
2. Заполнить остальные обязательные поля.
3. Нажать кнопку оформления заказа.

**Ожидаемый результат:** Номер телефона проходит проверку длины. При корректном заполнении остальных обязательных полей заказ оформляется.

**Фактический результат:** Заказ успешно оформляется

**Статус:** PASS

### TC-CHECKOUT-008 — Проверка ограничения длины номера телефона

**Связанное требование:** REQ-CHECKOUT-004

**Шаги:**
