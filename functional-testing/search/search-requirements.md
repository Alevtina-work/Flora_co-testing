# Требования к поиску

## REQ-SEARCH-001 — Поиск товаров по названию

**Описание**

При вводе пользователем поискового запроса приложение отображает только те товары, в названии которых содержится введённая последовательность символов.

### Уточнения требований

**1. Поиск без учёта регистра**

Поиск не должен зависеть от регистра введённых символов.

Пример: запросы `роз`, `Роз` и `РОЗ` должны давать одинаковый результат.

**Подтверждение разработчика:** да, поиск регистронезависимый.

**2. Поиск без пробелов между словами**

Поиск не должен автоматически игнорировать пробелы между словами в названии товара.

Пример: запрос `РозовыйАтлас` не должен находить товар `Розовый Атлас`.

**Подтверждение разработчика:** поиск без пробелов не предусмотрен в текущей версии.

**Дополнительная информация:** команда рассмотрит возможность добавления этой функции в следующей версии.

### Область проверки

- Поиск по полному названию товара.
- Поиск по части названия.
- Поиск без учёта регистра.
- Отображение результатов при отсутствии совпадений.
- Обработка пробелов в поисковом запросе.
- Взаимодействие поиска с выбранной категорией товаров.
- Обновление результатов при изменении поискового запроса.
