# Flora&Co — ручное тестирование

## О проекте

Этот репозиторий содержит примеры документации по ручному тестированию веб-приложения интернет-магазина растений.

Проект используется для практики основ тестирования, применения техник тест-дизайна, документирования результатов проверок, описания дефектов и предложений по улучшению пользовательского опыта.

## Тестируемое приложение

Веб-приложение интернет-магазина растений, позволяющее просматривать каталог товаров, искать растения, управлять избранным и корзиной, а также оформлять заказ.

## Выполненные виды тестирования

- Smoke Testing
- Функциональное тестирование
- Исследовательское тестирование
- Проверка адаптивности интерфейса

## Тестовая документация

В репозитории будут размещены:

- тест-кейсы;
- чек-листы;
- результаты тестовых прогонов;
- баг-репорты;
- предложения по улучшению пользовательского опыта.

## Область и ограничения тестирования

Тестируемое приложение работает на стороне клиента (frontend) и не использует серверную часть (backend) или базу данных.

Проверки ограничены доступной функциональностью приложения. Тестирование серверной логики и взаимодействия с базой данных в рамках этого проекта не проводится.

## Статус проекта

В процессе: документация постепенно дополняется по мере изучения техник и видов тестирования.
