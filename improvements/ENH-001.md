# ENH-001 — Добавить кнопку очистки поисковой строки

## Общая информация

**ID:** ENH-001  
**Раздел:** Каталог → Поиск  
**Тип:** Предложение по улучшению пользовательского опыта (UX Enhancement)  
**Статус:** Предложение на рассмотрении

## Текущее поведение

После выполнения поиска пользователь должен вручную удалять символы из поисковой строки, чтобы вернуться к отображению всех товаров.

Отдельная кнопка для очистки поискового запроса отсутствует.

## Предлагаемое поведение

Добавить в поисковую строку кнопку очистки, например в виде крестика.

При нажатии на кнопку:

1. Содержимое поисковой строки очищается.
2. Результаты поиска сбрасываются.
3. Отображаются все товары, соответствующие текущей выбранной категории.

## Польза для пользователя

Пользователь сможет быстрее сбрасывать результаты поиска, не удаляя символы вручную по одному.

## Обоснование

Во время исследовательского тестирования было замечено, что для сброса результатов поиска необходимо вручную очищать поисковую строку.

Добавление кнопки очистки может сделать поиск удобнее и сократить количество действий пользователя.
