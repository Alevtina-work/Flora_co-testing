# BUG-001 — Поиск из раздела «Избранное» переключает пользователя в каталог

## Общая информация

**ID:** BUG-001  
**Раздел:** Избранное → Поиск  
**Тип:** Функциональный  
**Severity:** Средняя  
**Priority:** Низкая  
**Статус:** Известное ограничение текущей версии

## Предусловия

- Открыт раздел «Избранное».
- В избранное добавлены товары «Снежная Гавань», «Розовый Атлас» и «Сиреневая Вуаль».
- Товар «Дикая Роза» отсутствует в избранном.

## Шаги воспроизведения

1. Открыть раздел «Избранное».
2. Ввести в поле поиска `роз`.
3. Проверить открытый раздел и отображаемые карточки товаров.

## Ожидаемый результат

Пользователь остаётся в разделе «Избранное».

Отображается только товар «Розовый Атлас», соответствующий поисковому запросу и находящийся в избранном.

Товар «Дикая Роза» не отображается.

## Фактический результат

После ввода `роз` приложение автоматически переключает пользователя в раздел «Каталог».

Поисковый запрос сохраняется в поле поиска. В результатах отображаются товары «Розовый Атлас» и «Дикая Роза». Товар «Розовый Атлас» отмечен как избранный.

## Дополнительная информация

Разработчик подтвердил, что поиск в разделе «Избранное» отдельно не реализован в текущей версии приложения. Команда планирует рассмотреть исправление в следующей версии.
