# BUG-003 — Оформление заказа без букв в имени или фамилии

## Общая информация

- **ID:** BUG-003
- **Раздел:** Оформление заказа → Контактные данные
- **Тип:** Functional
- **Severity:** Low
- **Priority:** Low
- **Статус:** New
- **Связанные требования:** REQ-CHECKOUT-001, REQ-CHECKOUT-002
- **Связанные тест-кейсы:** TC-CHECKOUT-001, TC-CHECKOUT-002

## Предусловия

1. Открыта страница оформления заказа.
2. В корзине находится хотя бы один товар.
3. Остальные обязательные поля заполнены корректными данными.

## Шаги воспроизведения

1. В поле «Имя» ввести `---`.
2. Заполнить поле «Фамилия» корректными данными.
3. Заполнить остальные обязательные поля корректными данными.
4. Нажать кнопку оформления заказа.

## Ожидаемый результат

Заказ не оформляется, поскольку поле «Имя» не содержит ни одной буквы. Приложение показывает сообщение о некорректном значении поля.

## Фактический результат

Заказ успешно оформляется, несмотря на то, что поле «Имя» содержит только дефисы.

## Дополнительная информация

Аналогичное поведение наблюдалось для поля «Фамилия»: значение, состоящее только из дефисов, также принималось при оформлении заказа.

Разработчик подтвердил, что оба поля должны содержать хотя бы одну букву. Дополнительные ограничения на расположение пробелов и дефисов для текущей версии не являются обязательными.
